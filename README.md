# google-translate-unofficial
Unofficial Google Translate. No API key required.

This repository hosts official ports of `google-translate-unofficial` for multiple programming languages. Each port lives in its own top-level folder and is published independently to its corresponding package registry.





## Ports
| Language | Folder | Registry | Package |
| --- | --- | --- | --- |
| Python | [`python/`](python) | PyPI | `google-translate-unofficial` |
| JavaScript | [`js/`](js) | npm | `google-translate-unofficial` |

See each folder's own README for installation and usage instructions specific to that language.
